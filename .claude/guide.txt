Phần 0. Đọc trước khi bắt đầu

0.1. Mục tiêu của tài liệu

Tài liệu hướng dẫn từng bước dựng và chạy toàn bộ phần mô phỏng CARLA của bài báo số 1. Đi hết tài liệu, nhóm có:

- môi trường CARLA và ROS 2 chạy ổn định;
- xe tự hành Tesla Model 3 (vật lý CARLA) được nhận dạng tham số và có bộ chuyển lệnh;
- bộ phát nhiễu định vị D0–D5;
- các kịch bản S1–S4;
- bộ dự báo, bộ hiệu chỉnh biên, bộ lập kế hoạch và bộ bám;
- chương trình chạy hàng loạt thí nghiệm E4–E8;
- script sinh hình và bảng cho bài báo.

Các bước đánh số C1–C9 khớp với khung chi tiết bài báo 1.

0.2. Quy ước bắt buộc

1.  Mã trong tài liệu là mã khung, chưa chạy kiểm chứng. Sinh viên phải chạy thử, sửa lỗi và ghi lại thay đổi vào git. Không coi mã mẫu là đúng khi chưa có phép thử ở mục “Kiểm tra”.
2.  Không sửa dữ liệu thô. Mọi xử lý ghi ra file mới.
3.  Mỗi lượt chạy lưu kèm: run_id, hạt giống, git commit, file cấu hình, phiên bản CARLA.
4.  Không xóa lượt chạy bất lợi. Lượt lỗi được đánh dấu và ghi lý do.
5.  Tham số xe lấy từ nhận dạng Tesla Model 3 trong CARLA (mục 2.4). Tham số nhiễu định vị lấy theo các mức thiết kế ở mục 3.2 (có nêu căn cứ). Giá trị chưa có căn cứ ghi rõ là TẠM.

0.4. Kiến trúc tổng thể

Phần lõi thuật toán được viết thành thư viện Python thuần av_core, gồm:

- dự báo;
- hiệu chỉnh;
- lập kế hoạch;
- bộ bám;
- tính khoảng cách.

Thư viện này được dùng theo hai cách:

1.  Chạy hàng loạt trên CARLA (chế độ khóa bước): một chương trình gọi trực tiếp av_core sau mỗi bước mô phỏng. Đây là cách chạy E1–E8: nhanh, tất định, lặp lại được theo hạt giống.
2.  Chạy qua ROS 2: các nút ROS 2 chỉ là lớp bọc mỏng quanh av_core. Dùng cho:
    - kiểm tra tương đương giữa hai cách chạy;
    - đo thời gian thực (E8);
    - chuyển nguyên sang xe Hunter SE.

                  ┌─────────────────────────────────────────────┐
                  │           av_core (Python thuần)             │
                  │ predictor · calibrator · planner · tracker   │
                  │ geometry (đa giác, khoảng cách) · logger     │

1.5. Kết nối và chế độ đồng bộ

File carla_env/world.py:

    import carla, random, numpy as np

    class SimWorld:
        """Quản lý kết nối CARLA, chế độ đồng bộ và dọn dẹp."""
        def __init__(self, host="localhost", port=2000, tm_port=8000,
                     town="Town03", dt=0.05, seed=0):
            self.client = carla.Client(host, port); self.client.set_timeout(30.0)
            self.world = self.client.load_world(town)
            self.dt = dt
            s = self.world.get_settings()
            s.synchronous_mode = True          # máy chủ chỉ chạy khi gọi tick()
            s.fixed_delta_seconds = dt         # bước cố định 0,05 s = 20 Hz
            s.no_rendering_mode = False        # True khi chạy hàng loạt không cần hình
            self.world.apply_settings(s)
            self.tm = self.client.get_trafficmanager(tm_port)
            self.tm.set_synchronous_mode(True)
            self.tm.set_random_device_seed(seed)
            self.world.set_pedestrians_seed(seed)
            random.seed(seed); np.random.seed(seed)
            self.actors = []

        def tick(self):
            return self.world.tick()           # trả về số khung hình

        def spawn(self, bp, tf):
            a = self.world.try_spawn_actor(bp, tf)
            if a is not None: self.actors.append(a)
            return a

        def close(self):
            """LUÔN gọi khi kết thúc, kể cả khi lỗi (dùng try/finally)."""
            self.client.apply_batch([carla.command.DestroyActor(a) for a in self.actors])
            s = self.world.get_settings()
            s.synchronous_mode = False; s.fixed_delta_seconds = None
            self.world.apply_settings(s)
            self.tm.set_synchronous_mode(False)

Lưu ý quan trọng. Nếu chương trình dừng giữa chừng mà không trả máy chủ về chế độ bất đồng bộ, máy chủ sẽ “đứng” chờ tick(). Khi đó khởi động lại máy chủ, hoặc chạy một script nhỏ đặt synchronous_mode=False.

Kiểm tra C1-b:

- Chạy 1200 bước (60 s mô phỏng).
- In thời gian thực đã trôi và số khung hình.
- Số khung hình phải tăng đúng 1 sau mỗi tick().

1.6. Quy đổi hệ tọa độ (rất dễ sai)

CARLA dùng hệ tọa độ tay trái của Unreal Engine: x tiến, y sang phải, z lên; góc yaw tính bằng độ. Thuật toán của nhóm dùng hệ tay phải như ROS (y sang trái, góc hướng tính bằng radian). Quy đổi ở một chỗ duy nhất:

    import math, carla

    def to_carla(px, py, psi, z=0.0):
        """Hệ tay phải (m, rad) -> Transform của CARLA."""
        return carla.Transform(carla.Location(x=px, y=-py, z=z),
                               carla.Rotation(yaw=-math.degrees(psi)))

    def from_carla(tf):
        """Transform của CARLA -> (px, py, psi) hệ tay phải."""
        return tf.location.x, -tf.location.y, -math.radians(tf.rotation.yaw)

Kiểm tra C1-c:

- Đặt xe tại (10, 5, 0,3 rad) qua to_carla, đọc lại bằng from_carla; sai số phải < 1e-6.
- Cho xe chạy vòng tròn sang trái trong av_core; quan sát trên CARLA, xe phải quay sang trái.

Phần 2. Bước C2 – Xe tự hành trong CARLA: Tesla Model 3

2.1. Lựa chọn và hệ quả

Xe tự hành trong mô phỏng là Tesla Model 3 có sẵn trong CARLA (blueprint vehicle.tesla.model3), chạy bằng mô hình vật lý của CARLA. Không dùng đồng mô phỏng.

Ưu điểm:

- Không phải tự viết mô hình động lực học.
- Sai số bám phát sinh tự nhiên từ động lực học của CARLA (trượt lốp, đáp ứng ga – phanh – lái), không phải giả lập. Điều này làm phần “sai số của xe tự hành” trong bài thuyết phục hơn.
- Xe cỡ thật, tốc độ đô thị (đến khoảng 30 km/h): phù hợp với kịch bản người đi bộ và xe máy, và quen thuộc với phản biện.

Hệ quả cần ghi nhớ:

- Bộ lập kế hoạch vẫn dùng mô hình xe đạp động học (mục 2.1 của bài). Tham số L, δ_(max), a_(max), a_(min) được trích và nhận dạng từ chính Tesla Model 3 trong CARLA (mục 2.3–2.4), không lấy từ Hunter SE.
- Kết quả CARLA của bài 1 là cho xe cỡ ô tô. Hunter SE (xe nhỏ) được hiệu chỉnh biên trực tiếp trên dữ liệu xe thật ở giai đoạn sau (bài 3). Không chuyển ngưỡng từ CARLA sang Hunter SE, vì hai xe khác nhau.
- Khoảng cách an toàn d_(s), tốc độ và tầm kích hoạt kịch bản đặt theo cỡ ô tô (mục 4.3).

2.2. Sinh xe và đọc tham số vật lý – file carla_env/ego.py

    import math, numpy as np, carla

    def spawn_tesla(sim, spawn_tf, role="hero"):
        bp = sim.world.get_blueprint_library().find("vehicle.tesla.model3")
        bp.set_attribute("role_name", role)
        ego = sim.spawn(bp, spawn_tf)          # vật lý CARLA BẬT (mặc định)
        sim.tick()                             # cần 1 tick để vật lý khởi tạo
        return ego

    def vehicle_params(ego):
        """Trích chiều dài cơ sở, góc lái lớn nhất, kích thước từ CARLA."""
        pc = ego.get_physics_control()
        w = pc.wheels                          # thứ tự: FL, FR, RL, RR
        # vị trí bánh xe (cm, hệ toàn cục, tại thời điểm gọi) -> m
        front = np.mean([[w[0].position.x, w[0].position.y], [w[1].position.x, w[1].position.y]], 0)/100
        rear  = np.mean([[w[2].position.x, w[2].position.y], [w[3].position.x, w[3].position.y]], 0)/100
        L = float(np.linalg.norm(front - rear))
        dmax = math.radians(max(w[0].max_steer_angle, w[1].max_steer_angle))
        ext = ego.bounding_box.extent          # nửa kích thước (m)
        # khoảng từ tâm cầu sau đến đuôi xe: dùng vị trí bánh sau so với tâm bounding box
        tf = ego.get_transform(); fwd = tf.get_forward_vector()
        c = np.array([tf.location.x + ego.bounding_box.location.x, tf.location.y])  # gần đúng
        rear_overhang = float(ext.x - np.dot(c - rear*1.0, [fwd.x, fwd.y]))         # kiểm tra bằng tay!
        return dict(L=L, delta_max=dmax, length=2*ext.x, width=2*ext.y,
                    rear_overhang=rear_overhang, mass=pc.mass)

Lưu ý:

- vehicle_params cần kiểm tra bằng tay một lần: in ra L, δ_(max), kích thước, rồi so với hình xe trong CARLA. Ghi giá trị cuối vào configs/tesla_model3.yaml và dùng cố định từ đó.
- Góc lái thực của bánh trước phụ thuộc cả đường cong lái theo tốc độ (steering_curve). Vì vậy quan hệ lệnh lái – góc lái tương đương phải nhận dạng (mục 2.4), không suy trực tiếp từ max_steer_angle.
- Gốc của đa giác xe đặt tại tâm cầu sau, theo đúng mô hình trong bài. Vị trí trả về của CARLA là tâm actor; quy đổi qua rear_overhang và L.

2.3. Bộ chuyển lệnh – file av_core/actuation.py

Bộ bám (Pure Pursuit) cho ra lệnh (v_(cmd), δ_(cmd)). CARLA nhận VehicleControl(throttle, steer, brake). Bộ chuyển lệnh gồm:

- một PI vận tốc;
- một bảng tra góc lái → steer;
- một bộ đệm trễ để tạo các điều kiện D4, D5.

    import numpy as np, carla
    from collections import deque

    class TeslaActuator:
        def __init__(self, p, dt=0.05, delay_s=0.0):
            self.kp, self.ki, self.dt = p["kp_v"], p["ki_v"], dt
            self.steer_gain = p["steer_gain"]           # rad -> [-1,1], nhận dạng ở mục 2.4
            self.i = 0.0
            n = int(round(delay_s / dt))
            self.buf = deque([(0.0, 0.0)]*(n + 1), maxlen=n + 1)

        def set_delay(self, delay_s):                   # dùng cho D4/D5
            n = int(round(delay_s / self.dt)); old = list(self.buf)
            self.buf = deque((old + [old[-1]]*(n + 1))[-(n + 1):], maxlen=n + 1)

        def __call__(self, v_meas, v_cmd, d_cmd):
            self.buf.append((v_cmd, d_cmd)); v_ref, d_ref = self.buf[0]   # lệnh đã trễ
            e = v_ref - v_meas; self.i = np.clip(self.i + e*self.dt, -5, 5)
            u = self.kp*e + self.ki*self.i
            thr, brk = (float(np.clip(u, 0, 1)), 0.0) if u >= 0 else (0.0, float(np.clip(-u, 0, 1)))
            if v_ref < 0.05 and v_meas < 0.3: thr, brk = 0.0, 1.0      # giữ xe đứng yên
            steer = float(np.clip(self.steer_gain*d_ref, -1, 1))
            return carla.VehicleControl(throttle=thr, steer=steer, brake=brk)

Lưu ý: v_meas ở đây là vận tốc đo (từ bộ định vị hoặc odometry có nhiễu), không phải vận tốc thật của CARLA.

File configs/tesla_model3.yaml (điền sau khi chạy mục 2.2 và 2.4):

Phần 3. Bước C3 – Cảm biến, định vị và suy giảm có kiểm soát

3.1. Nguyên tắc

3.2. Bộ phát nhiễu – file av_core/noise.py

    import numpy as np

    class LocalizationNoise:
        """Sai số định vị theo trạng thái RTK: 'fixed', 'float', 'lost'.
        fixed/float: nhiễu trắng + thiên lệch Gauss–Markov.
        lost: dead-reckoning, sai số tích lũy theo quãng đường và thời gian."""
        def __init__(self, p, rng):
            self.p, self.rng = p, rng
            self.bias = np.zeros(2); self.dr = np.zeros(3)   # thiên lệch (x,y); dead-reckoning (x,y,psi)

        def sample(self, state, v, psi, dt):
            """Trả về sai số (ex, ey, epsi) trong hệ toàn cục; psi là góc hướng thật của xe."""
            g = self.p[state]
            if state in ("fixed", "float"):
                beta = np.exp(-dt / g["tau_bias"])
                self.bias = beta*self.bias + np.sqrt(1 - beta**2)*g["sigma_bias"]*self.rng.standard_normal(2)
                exy = self.bias + g["sigma_white"]*self.rng.standard_normal(2)
                epsi = g["sigma_yaw"]*self.rng.standard_normal()
                self.dr[:] = [exy[0], exy[1], epsi]        # điểm xuất phát khi chuyển sang mất GNSS
                return tuple(self.dr)
            # lost: sai số hướng tích lũy do thiên lệch và nhiễu gyro
            self.dr[2] += g["gyro_bias"]*dt + g["sigma_gyro"]*np.sqrt(dt)*self.rng.standard_normal()
            # sai số vị trí: theo phương dọc (tỉ lệ odometry) và phương ngang (do sai số hướng)
            e_long = v*dt*g["odo_scale"]*self.rng.standard_normal()
            e_lat = v*dt*np.sin(self.dr[2])
            self.dr[0] += e_long*np.cos(psi) - e_lat*np.sin(psi)
            self.dr[1] += e_long*np.sin(psi) + e_lat*np.cos(psi)
            return tuple(self.dr)

4.2. Mã khung – file carla_env/scenarios.py

    import numpy as np, carla, math
    from carla_env.coords import to_carla, from_carla

    class CrossingPedestrian:
        """S1: người đi bộ sang đường vuông góc với hướng xe tại điểm xung đột P."""
        def __init__(self, sim, P, ego_heading, rng, cfg):
            self.v = rng.uniform(*cfg["speed"])                 # 0.8–1.8 m/s
            self.s_trig = rng.uniform(*cfg["trigger_dist"])     # m
            self.stop_mid = rng.random() < cfg["p_stop_mid"]    # dừng giữa đường
            side = rng.choice([-1, 1])
            n = np.array([-math.sin(ego_heading), math.cos(ego_heading)])  # pháp tuyến trái
            self.start = np.array(P) + side*cfg["lateral_start"]*n
            self.dir = -side*n
            bp = rng.choice(sim.world.get_blueprint_library().filter("walker.pedestrian.*"))
            self.actor = sim.spawn(bp, to_carla(*self.start, ego_heading, z=1.0))
            self.active, self.t_stop, self.P = False, None, np.array(P)

        def update(self, ego_xy, t):
            if not self.active and np.linalg.norm(ego_xy - self.P) < self.s_trig:
                self.active = True
            speed = self.v if self.active else 0.0
            if self.stop_mid and self.active:
                pos = np.array(from_carla(self.actor.get_transform())[:2])
                if np.linalg.norm(pos - self.P) < 0.3 and self.t_stop is None: self.t_stop = t
                if self.t_stop is not None and t - self.t_stop < 2.0: speed = 0.0
            d = carla.Vector3D(x=self.dir[0], y=-self.dir[1], z=0.0)   # đổi sang hệ CARLA
            self.actor.apply_control(carla.WalkerControl(direction=d, speed=speed))

    class CrossingMotorbike:
        """S2: xe máy cắt ngang qua điểm P với góc cắt và vận tốc ngẫu nhiên."""
        def __init__(self, sim, P, ego_heading, rng, cfg):
            self.v = rng.uniform(*cfg["speed"])                          # 3–8 m/s
            ang = math.radians(rng.uniform(*cfg["cross_angle_deg"]))     # 30–90 độ
            side = rng.choice([-1, 1])
            self.heading = ego_heading + side*ang
            self.s_trig = rng.uniform(*cfg["trigger_dist"])
            L0 = cfg["approach_len"]
            self.P = np.array(P)
            self.start = self.P - L0*np.array([math.cos(self.heading), math.sin(self.heading)])
            bp = sim.world.get_blueprint_library().find(rng.choice(cfg["blueprints"]))
            self.actor = sim.spawn(bp, to_carla(*self.start, self.heading, z=0.3))
            self.actor.set_simulate_physics(False)
            self.s, self.active = 0.0, False

        def update(self, ego_xy, t, dt):
            if not self.active and np.linalg.norm(ego_xy - self.P) < self.s_trig:
                self.active = True
            if self.active: self.s += self.v*dt
            xy = self.start + self.s*np.array([math.cos(self.heading), math.sin(self.heading)])
            self.actor.set_transform(to_carla(xy[0], xy[1], self.heading, z=0.3))

    import numpy as np
    def predict_cv(track, H, dt):
        """track: mảng [[t, x, y], ...] (≥ 2 điểm gần nhất). Trả về H vị trí tương lai."""
        (t0, x0, y0), (t1, x1, y1) = track[-2], track[-1]
        v = np.array([x1 - x0, y1 - y0]) / (t1 - t0)
        return np.array([[x1, y1] + v*dt*k for k in range(1, H + 1)])

6.1. Đa giác và khoảng cách – file av_core/geometry.py

    import numpy as np
    from shapely.geometry import Polygon

    def rect_polygon(px, py, psi, length, width, rear_overhang=0.0):
        """Đa giác chữ nhật của xe; gốc (px,py) tại tâm cầu sau (xe tự hành)
        hoặc tâm hình (tác nhân, đặt rear_overhang = length/2)."""
        c, s = np.cos(psi), np.sin(psi)
        xs = np.array([-rear_overhang, length - rear_overhang, length - rear_overhang, -rear_overhang])
        ys = np.array([-width/2, -width/2, width/2, width/2])
        return Polygon(np.c_[px + c*xs - s*ys, py + s*xs + c*ys])

    def poly_distance(A, B):
        return A.distance(B)        # = 0 nếu giao nhau

- Lưới ứng viên:

  - vận tốc đích 0…v_(max), bước 0,5 m/s;
  - thời gian 3, 4, 5 s.
- Đầu ra mỗi chu kỳ (10 Hz):
  - quỹ đạo kế hoạch lấy mẫu tại τ = 1..H (cùng bước với dự báo);
  - cờ fallback.

6.3. Bộ bám Pure Pursuit – file av_core/tracker.py

    import numpy as np
    def pure_pursuit(x, path_xy, path_v, L, ld_min=1.0, k_ld=0.5, dmax=0.4):
        """x = [px,py,psi,v,delta]; path_xy: (N,2); trả về (v_cmd, delta_cmd)."""
        ld = max(ld_min, k_ld*x[3])
        d = np.linalg.norm(path_xy - x[:2], axis=1)
        i0 = int(np.argmin(d))
        idx = next((i for i in range(i0, len(path_xy)) if d[i] >= ld), len(path_xy) - 1)
        dx, dy = path_xy[idx] - x[:2]
        alpha = np.arctan2(dy, dx) - x[2]
        delta = np.arctan2(2*L*np.sin(alpha), ld)
        return float(path_v[idx]), float(np.clip(delta, -dmax, dmax))

Bộ bám chạy ở 20 Hz (mỗi bước CARLA). Bộ bám dùng tư thế ước lượng, không dùng giá trị chuẩn. Đây chính là nơi sai số định vị đi vào vòng kín.

6.4. Bộ đánh giá trễ H bước – file av_core/evaluator.py

Tại thời điểm lập kế hoạch t chưa biết khoảng cách thật. Phải chờ H bước mới tính được R.

    import numpy as np
    from collections import deque
    from av_core.geometry import rect_polygon, poly_distance

    class DelayedEvaluator:
        def __init__(self, H, ego_dims, sigma_tau, d_s):
            self.H, self.ego_dims, self.sigma, self.d_s = H, ego_dims, np.asarray(sigma_tau), d_s
            self.pending = deque()

        def add_plan(self, t, plan_poses, pred_agents, meta):
            """plan_poses: (H,3) tư thế kế hoạch; pred_agents: {id: (H, 3) tư thế dự báo, dims}."""
            self.pending.append(dict(t=t, plan=plan_poses, pred=pred_agents, meta=meta,
                                     true_ego=[], true_ag=[]))

        def add_truth(self, ego_pose, agents_truth):
            """Gọi ở mỗi bước lập kế hoạch (10 Hz) với giá trị chuẩn tại thời điểm đó."""
            for rec in self.pending:
                if len(rec["true_ego"]) < self.H:
                    rec["true_ego"].append(ego_pose); rec["true_ag"].append(agents_truth)
            out = []
            while self.pending and len(self.pending[0]["true_ego"]) == self.H:
                out.append(self._finalize(self.pending.popleft()))
            return out

        def _finalize(self, rec):
            rows, R = [], -np.inf
            for k in range(self.H):
                ego_plan = rect_polygon(*rec["plan"][k], *self.ego_dims)
                ego_true = rect_polygon(*rec["true_ego"][k], *self.ego_dims)
                for aid, (pred, dims) in rec["pred"].items():
                    if aid not in rec["true_ag"][k]: continue        # tác nhân đã rời vùng
                    d_plan = poly_distance(ego_plan, rect_polygon(*pred[k], *dims))
                    d_true = poly_distance(ego_true, rect_polygon(*rec["true_ag"][k][aid], *dims))
                    R = max(R, (d_plan - d_true) / self.sigma[k])
                    rows.append(dict(**rec["meta"], t=rec["t"], tau=k + 1, agent_id=aid,
                                     d_plan=d_plan, d_true=d_true,
                                     violation=int(d_true < self.d_s)))
            return dict(meta=rec["meta"], t=rec["t"], R=R, rows=rows)

- Với ước lượng σ_(τ) ở giai đoạn đầu, chạy với σ_(τ) = 1. Ghi (d̂ − d) thô theo từng τ để ước lượng σ_(τ) sau (mục 8.1).
- _finalize phải ghi cả sai số tác nhân và sai số xe để tính B1, B3 và kiểm tra Mệnh đề 3:
  - err_agent = độ lệch tư thế dự báo – thật của tác nhân;
  - err_ego_pos, err_ego_yaw = độ lệch kế hoạch – thật của xe.

Kiểm tra C6-a (kiểm tra đơn vị bộ đánh giá):

- Cho kế hoạch trùng tư thế thật và dự báo trùng tác nhân thật: R phải bằng 0.
- Dịch tác nhân thật lại gần xe 0,5 m: R phải xấp xỉ 0, 5/σ_(τ).

7.1. Vòng lặp chính (khóa bước)

    def run_episode(cfg, seed, method, scenario, condition, q_table, out_path):
        rng = np.random.default_rng(seed)
        sim = SimWorld(port=cfg.port, tm_port=cfg.tm_port, town=cfg.town, dt=0.05, seed=seed)
        try:
            ego = spawn_tesla(sim, cfg.route.start_tf)
            act = TeslaActuator(cfg.vehicle, dt=sim.dt)
            apply_condition(act, cfg.conditions[condition], rng)        # đặt trễ D4/D5
            agents = build_scenario(sim, scenario, cfg, rng)
            noise = LocalizationNoise(cfg.noise, rng)
            predictor, planner = make_predictor(cfg), make_planner(cfg, method)
            calib = make_calibrator(method, q_table)       # B0..B6, ĐX-1..3
            evalr = DelayedEvaluator(cfg.H, cfg.ego_dims, cfg.sigma_tau, cfg.d_s)
            logger = EpisodeLogger(out_path, meta=dict(seed=seed, method=method,
                                   scenario=scenario, condition=condition))
            ctrl = carla.VehicleControl(brake=1.0); x_true = read_state(ego, cfg.vehicle); plan = None
            for k in range(int(cfg.T_max / sim.dt)):
                t = k*sim.dt
                ego.apply_control(ctrl)                                  # 1. gửi lệnh (đã trễ)
                for a in agents: a.update(x_true[:2], t, sim.dt)         # 2. tác nhân
                sim.tick()                                               # 3. CARLA tiến 1 bước
                x_true = read_state(ego, cfg.vehicle)                    #    tư thế thật tại tâm cầu sau
                rtk = rtk_state(condition, t, cfg, rng)                  # 4. trạng thái RTK
                e = noise.sample(rtk, x_true[3], x_true[2], sim.dt)
                x_est = x_true.copy(); x_est[:3] += e                    #    tư thế ước lượng
                truth = {a.id: a.pose() for a in agents if a.visible(x_true)}
                if k % 2 == 0:                                           # 5. 10 Hz: lập kế hoạch
                    tracks = update_tracks(truth, t)                     #    (có thể thêm nhiễu nhận thức)
                    pred = predictor(tracks)
                    q = calib.q(group=rtk, t=t)
                    plan = planner.plan(x_est, pred, margin=cfg.sigma_tau*q)
                    evalr.add_plan(t, plan.poses_H, pred, meta=dict(group=rtk, q_used=q,
                                   fallback=plan.fallback))
                    for res in evalr.add_truth(x_true[:3], truth):
                        logger.write(res); calib.feedback(res)           # ĐX-3 cập nhật trễ H bước
                v_cmd, d_cmd = pure_pursuit(x_est, plan.path_xy, plan.path_v, cfg.vehicle["L"],
                                            dmax=cfg.vehicle["delta_max"])
                ctrl = act(x_est[3], v_cmd, d_cmd)                       # 6. lệnh cho bước sau
                logger.step(t, x_true, x_est, v_cmd, d_cmd, truth)
                if reached_goal(x_true, cfg) or collided(x_true, truth, cfg): break
        finally:
            logger.close(); sim.close()

Thứ tự trong một bước là cố định; không được đảo:

1.  gửi lệnh điều khiển (đã qua bộ đệm trễ);
2.  tác nhân cập nhật;
3.  CARLA tick;
4.  đo (thêm nhiễu);
5.  lập kế hoạch (10 Hz);
6.  bộ bám và bộ chuyển lệnh tính lệnh cho bước sau.

8.1. Ước lượng σ_(τ) (hạt giống 200–249)

    def estimate_sigma(df, q=0.9, floor=0.05):
        """df: bảng chu kỳ; lấy max theo tác nhân của (d_plan - d_true) cho từng (chu kỳ, tau)."""
        g = df.assign(s=df.d_plan - df.d_true).groupby(["run_id", "t", "tau"]).s.max()
        sig = g.groupby("tau").quantile(q).clip(lower=floor)
        return sig.sort_index().to_numpy()      # mảng độ dài H, lưu vào configs/sigma_tau.npy

8.2. Lấy thưa và tính ngưỡng – av_core/calibrator.py

    import numpy as np

    def thin(df_R, every_s=2.0):
        """Giữ 1 chu kỳ mỗi every_s giây trong mỗi lượt, giảm tương quan thời gian."""
        df_R = df_R.sort_values(["run_id", "t"])
        keep = (df_R.t // every_s).astype(int)
        return df_R.groupby(["run_id", keep]).head(1)

    def conformal_q(R, alpha):
        R = np.sort(np.asarray(R)); n = len(R)
        k = int(np.ceil((n + 1)*(1 - alpha)))
        return np.inf if k > n else R[k - 1]

    def q_by_group(df_R, alpha, groups=("fixed", "float", "lost")):
        out = {}
        for g in groups:
            R = df_R.loc[df_R.group == g, "R"].to_numpy()
            out[g] = conformal_q(R, alpha) if len(R) >= int(np.ceil(1/alpha)) - 1 else None
        return out   # None -> dùng ngưỡng chung, phải ghi rõ trong bài

    from statsmodels.stats.proportion import proportion_confint
    def coverage(df_R, q_col="q_used"):
        ok = (df_R.R <= df_R[q_col]).to_numpy()
        lo, hi = proportion_confint(ok.sum(), len(ok), alpha=0.05, method="beta")  # Clopper–Pearson
        return ok.mean(), lo, hi, len(ok)
